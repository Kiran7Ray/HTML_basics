# 🌐 HTML Basics 

This repository contains **basic HTML concepts and examples** designed for beginners.  
It covers core HTML structure, commonly used tags, semantic elements, forms, media, and basic CSS usage.

---

## 📌 1. HTML Document Structure

### `<!DOCTYPE html>`

Defines the document type as **HTML5** and ensures modern browser rendering.

### `<html>`

Root element of the HTML document. All content is wrapped inside this tag.

### `<head>`

Contains metadata and information about the document (not displayed on the page).

### `<body>`

Holds all the visible content of the webpage.

---

## 📌 2. Metadata Tags

Metadata provides information about the webpage.

- `<title>` → Page title shown in browser tab
- `<meta charset="UTF-8">` → Character encoding
- `<meta name="viewport">` → Responsive layout for mobile devices
- `<meta name="keywords">` → SEO keywords
- `<meta name="description">` → Page summary
- `<meta name="author">` → Author information

📱 **Viewport Effect:**  
With viewport → Page fits mobile screen properly  
Without viewport → Page appears zoomed on mobile

---

## 📌 3. Headings and Paragraphs

### Headings (`<h1>` to `<h6>`)

Used to define titles and subheadings.  
`<h1>` is the most important, `<h6>` is the least.

### Paragraph (`<p>`)

Defines a block of text with spacing.

---

## 📌 4. Text Formatting Tags

Used to change appearance or meaning of text:

- `<strong>` → Important text (semantic bold)
- `<b>` → Bold text (visual only)
- `<em>` → Emphasized text (semantic italic)
- `<i>` → Italic text (visual only)
- `<mark>` → Highlighted text
- `<del>` → Deleted text (strike-through)
- `<ins>` → Inserted text (underlined)

---

## 📌 5. Links and Images

### Anchor Tag (`<a>`)

Used to create hyperlinks using the `href` attribute.

### Image Tag (`<img>`)

Displays images using:

- `src` → Image path
- `alt` → Alternative text (important for accessibility)

---

## 📌 6. Lists

### Unordered List (`<ul>`)

Displays bullet points.

### Ordered List (`<ol>`)

Displays numbered items.

### List Item (`<li>`)

Defines each list entry.

---

## 📌 7. Tables

Used to display tabular data.

- `<table>` → Table container
- `<tr>` → Table row
- `<th>` → Header cell
- `<td>` → Data cell

Lists can also be placed inside table cells.

---

## 📌 8. Multimedia Elements

### Image (`<img>`)

Used to display images.

### Audio (`<audio>`)

Plays audio files with `controls`.

### Video (`<video>`)

Plays video files with playback controls.

HTML5 supports multimedia without plugins.

---

## 📌 9. Iframe

### `<iframe>`

Embeds another webpage inside the current page.

Common attributes:

- `src` → URL
- `width`, `height` → Size
- `title` → Accessibility

---

## 📌 10. Forms

Forms collect user input.

### `<form>`

Container for form elements.

### Common Input Elements:

- `<input type="text">`
- `<input type="password">`
- `<textarea>` → Multi-line input
- `<select>` and `<option>` → Dropdown menu
- `<button>` → Submit action

---

## 📌 11. Login Form

A login form typically includes:

- Username input
- Password input
- Submit button

Forms may use CSS for better layout and appearance.

---

## 📌 12. Semantic HTML Tags

Semantic tags give **meaning** to page structure and improve SEO and accessibility.

- `<header>` → Top section
- `<nav>` → Navigation links
- `<main>` → Main content
- `<section>` → Content grouping
- `<article>` → Independent content
- `<aside>` → Side information
- `<footer>` → Footer section

---

## 📌 13. CSS (Cascading Style Sheets)

CSS is used to style HTML elements.

### Ways to use CSS:

- Inline CSS (`style` attribute)
- Internal CSS (`<style>` tag)
- External CSS (`.css` file)

CSS controls:

- Colors
- Fonts
- Layout
- Spacing
- Borders

---

This repository provides a **strong foundation in HTML basics**, covering:
